# GitHub 代码版图

独立的 GitHub 仓库、Pull Request、协作者和代码事实工作台。

## 本地开发

```bash
npm install
npm run dev
```

打开 <http://localhost:3000/>。

## 范围

- `/`：GitHub 仓库版图
- `/review`：Pull Request 审查与合并治理
- `/api/v1/github-portfolio`：仓库、协作者和报告 API
- `/api/v1/github-portfolio/pull-requests`：PR 详情、代码审查和合并 API

本项目只包含 GitHub 管理功能。
